## Проект Яндекс Афиша

Используемая версия Python 3.11.0

./data/load_database.py - исполняемый файл, что подгружает таблицу из базы данные с яндекс афиши.
./data/afisha.csv - данные выгруженные с базы данных.
./data/final_tickets_tenge_dt.csv - датафрейм с курсом теньге к рублю.

afisha.ipynb - jupyter тетрадка со всеми исследованиями.
